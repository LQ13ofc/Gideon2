# B4 — pacote Linux offline relocável (Core + App + Base)

Escopo B4.1: diretório de pacote autocontido, relocável, verificável por hash,
que roda S1 (wake replay→STT→comando sandbox→TTS virtual) a partir de um prefixo
diferente do repositório, SEM acesso ao repositório/target/uv do host.
Fora de escopo: Flatpak/portal, Wayland real, áudio físico, autostart/systemd,
instalação no host do usuário, assinatura/atualização de pacote (B4.2+).

## Layout `gideon-base-<versão>/`

bin/gideon-base (release), bin/gideon-app (launcher da UI), scripts/ (somente
workers e app/: wake_worker, stt_worker, tts_worker, command_worker),
app/ (QML+bridge+visual), runtime/python (cópia do CPython uv usado pelos venvs),
venvs/{a1,stt,tts,ui} (cópias com bin/python relativo→runtime e pyvenv.cfg home
reescrito), assets/ (somente runtime: modelo wake `asset_root`, VAD, modelo STT,
TTS root/config/voz/tokenizer; NENHUM corpus de fixture/QA),
templates/ (manifests com marcador @PREFIX@), PACKAGE.json (versão, commit,
target, sha256+size de cada arquivo, sem symlinks fora do prefixo).

## Contrato

1. Core ganha `--home ABS_DIR` (padrão: CARGO_MANIFEST_DIR para dev). Substitui
   env!("CARGO_MANIFEST_DIR") em transport.rs (script dir e bind). Absoluto,
   diretório, não symlink; scripts resolvidos como `<home>/scripts/<worker>.py`.
2. Rust continua exigindo caminhos absolutos e hashes de pack: o pacote não
   relaxa validações. `bin/gideon-configure PREFIX_STATE` renderiza templates
   substituindo @PREFIX@ pelo prefixo real em diretório de estado privado (0700),
   recalcula os pins do pack e grava `pack.json`; nunca escreve fora do estado.
3. `bin/gideon-core` (launcher sh) = configure idempotente + exec do Core com
   `--home`, `--base-pack`, `--tts-virtual`, `--commands-sandbox`. Sem rede,
   sem download, sem instalar plugin/LLM no first-run.
4. Verificação de integridade: `gideon-verify` recalcula PACKAGE.json; qualquer
   arquivo alterado/ausente/extra → falha fechada e código de saída ≠ 0.
5. Gate verify_b4_package.py: constrói pacote em dir efêmero, move para prefixo
   NOVO (nome diferente), roda Core em bwrap onde o repositório e ~/.local/share/uv
   NÃO estão montados (somente prefixo + /usr + estado privado), executa S1
   completo por PCM virtual, hub catálogo+aprovação+import+install+remove,
   restart, adultera um arquivo → verify falha. Regressões Base no mesmo binário.
