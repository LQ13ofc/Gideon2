## 4. Decisões tomadas nesta entrega (para revisão)

1. Exportação vai para arquivo, não para a tela: uma exportação completa passa do limite de 64 KiB de uma resposta IPC.
   Respostas pessoais acima de 32 KiB são recusadas com `reply_too_large` (a aba Histórico não abre sessões grandes).
2. Gatilho de hábito por voz: só a frase exata (sem maiúsculas, espaços extras ou pontuação final). Frase de hábito
   pausado não dispara. A sessão de voz termina com `command_success` ou `command_failed`, sem recibo.
3. N-5 por fila: uma vaga, aceita texto e agente. A fila roda quando a sessão termina (no próximo `expire`). Não há
   intercalação em tempo real.
4. Retenção governa histórico, não memória curada (mesma decisão do WP10a §3).
