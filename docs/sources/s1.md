**Entregar:** Core Rust mínimo, logging privado limitado, state machine de sessão, request IDs, deadlines/cancel tokens, scheduler leve, capabilities e policy mínima, storage/config private, source/sink virtuais e production adapters separados, harness CLI/headless.

## Gate A1 — wake real como primeiro recurso
**Contrato:** WakeEngine consumes frames + timestamps, returns \{phrase_id, scores/confidence, time span, engine/version\}. Detector escolhido deve declarar conjunto de frases suportadas; target inicial "Hey Gideon". Frase não pode ser declarada arbitrary reconfigurable sem backend ou treino adequado; "Okay Gideon" pode ser candidata futura, não default escondido.
**Técnica:** baixa carga idle, ring buffer pre-roll, wake+noise negatives, thresholds versionados e cooldown. Quando wake falha/sai worker, fail-closed/restart controlado.
**Teste:** horas de fixture/silence/speech negatives autorizadas e hash manifest; check recall e false activation no corpus; valores como 99,9% só metas futuras, não aprovação de hardware.
**Gate:** dentro do Core A0, wake sample desencadeia sessão uma vez.
## Gate A2 — captura de fala acionada
**Contrato:** WakeDetected → AudioSession.capture(pre-roll) → AudioChunks com monotonic ts/channels/sample-rate; EOF/errors typed; no persistent voice record. Implementar VAD/timeout/capture-end policy como parte do fluxo.
**Testes:** pré-roll junto à primeira palavra, silêncio, fala longa, interrupt/cancel, backpressure, hotplug simulado, producer fail, partial frames e OOM preventive.
**Gate:** audio sequence resultada por A1 real com buffers limitados e consumidores não bloqueantes.
## Gate A3 — STT enquanto a fala ocorre
**Contrato:** SttEngine.startSession+acceptFrames yields TranscriptPartial/revision+TranscriptFinal/end. Separar RawTranscript do texto normalizado; Confidence/Unknown/NoSpeech e RecognitionContext reservados para evolução, sem inventar nomes.
**Técnica:** um backend de referência certificado/pinado para distribuição Base, CPU path; outros engines só se necessários por bug de compatibilidade. Internal voice components with preflight/hash/version files do NOT constitute user Model Manager.
**Testes:** PCM específico → A1→A2→STT partial e final; latência de cada partial, WER/entity e cancel/late results; execução nunca disparada por partials; concorrência de sessões.
**Gate:** replay streaming passa pelo caminho de Core real e produz transcrição legível antes do fim do áudio, em cenários elegíveis.
