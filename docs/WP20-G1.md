## 2. Decisões e desvios

- **Plural sem `numerusform`.** `scripts/test_i18n.py` lê cada `<translation>` como texto simples; uma mensagem com `numerusform` falharia em `test_no_message_is_unfinished_or_empty`. Usei um ramo por contagem com duas mensagens (ex.: `"1 mensagem"` / `"%1 mensagens"`, `"1 proposta pendente"` / `"%1 propostas pendentes"`). Se o teste passar a ler `numerusform`, dá para migrar.
- **Sem concatenação de frases.** Cada frase com dado usa `qsTr("... %1 ...").arg(...)`. Separadores ` · ` ficam como na fonte.
- **AProposalCard: risco pela chave do Core.** A comparação de risco (`alto`/`médio`) saiu da palavra traduzida e passou a usar `destructive`/`public` (alto), `state_changing` (médio) e `read` (baixo). Comportamento igual ao anterior: a confirmação de risco alto continua aparecendo para as mesmas chaves. Não há teste automatizado para isso; verifiquei pela leitura do código.
- **Conversa**: o rótulo de quem fala (Você / Gideon) e o estado da bolha (cancelada / erro) passaram a vir de funções, sem texto colado.
- **Hoje**: os chips Wake, Entrada e Modo, a frase "Passo X de Y" e as mensagens de HUD usam `qsTr` com `%1`. Textos de Core (`core.result`, `core.agentStateLabel`, `core.chatStateLabel`) seguem como vêm.
- **Lista de pendentes**: removi os 14 arquivos de `PENDING_FILES` em `scripts/test_i18n.py` (8 edições, uma por linha).
- **Glossário**: não editei `docs/I18N_GLOSSARY.md` (arquivo compartilhado). Termos novos que usei e que precisam entrar lá: Abortar = Abort / Interrompre; Iniciar = Start / Démarrer; Apagar = Delete / Supprimer; Pausar / Retomar = Pause / Resume (Mettre en pause / Reprendre); Ferramenta = Tool / Outil; Origem = Source / Origine; Prévia = Preview / Aperçu; Usar = Use / Utiliser; Desativar = Deactivate / Désactiver; Autorizar / Negar = Authorize / Deny (Autoriser / Refuser); Risco = Risk / Risque; Efeito = Effect / Effet; Passo = Step / Étape.
- **"Não guardar"** (PRetentionNote, texto da opção de Privacidade): en "Don't keep", fr "Ne pas conserver". Precisa bater com `CfgPrivacidade` quando essa tela for migrada.
