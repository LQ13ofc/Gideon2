# B1 — App conectado

Qt/QML thin: estados/transcrição parcial e final/efeito/fala vêm somente do IPC v1.
Socket privado + peer credential do kernel; IDs únicos, validação de envelopes,
limite de resposta e reconexão. Sessão u64 é string na UI (sem perda por JS double).
Sem parser/motor/autoridade duplicados. Cancel passa pelo owner; offline limpa
estado velho e bloqueia ações. Nenhuma página LLM/model manager antes do plugin.

Dashboard, status Aura, conversa corrente, Cancel, Diagnostics. Configurações e
Hub têm controles indisponíveis até B2/B3, com limites de dispositivos/voz claros.
Sem armazenamento de conversas. Sem abrir janela na sessão pessoal.

Gate: Qt offscreen em namespace HOME/XDG/tmpfs; Core real S1, texto/estados/resultado
verificado/PCM observáveis pela UI; cancel, foco/teclado/tamanhos/HiDPI/acessibilidade,
kill/reconnect/stale/delta e regressão S1. B1 IN_PROGRESS até evidência passar.

B1 AUTO_VERIFIED/PHYSICAL_PENDING: 32 checks Qt nativo em quatro cenários (voz S1,
Cancel por Space, kill/restart/reconnect e SIGSTOP/watchdog/SIGCONT). Partial/final,
efeito verificado, PCM concluído e controles são do Core real. Render 640×520 a
scale 2 (1280×1040), foco/teclado e accessible name verificados; imagem offscreen
inspecionada. Ui não emite delta para snapshot idêntico. Frases/modelos/devices
futuros permanecem indisponíveis; nenhum painel LLM/Model Manager.

Correções: runtime Python symlink exige mount do alias; registrar QQuickWindow
antes da criação QML para grabWindow; só declarar Connected depois do envelope
v1 validado, não na conexão de transporte. Shutdown elimina janela antes do bridge.
Core valida SO_PEERCRED além de root/socket privados; IDs u64 viram strings apenas
na apresentação. Campo transcript.source distingue voz de texto explícito.

Entrada de texto é test-only (--virtual-input + --commands-sandbox): passa pelo
MESMO parser/grant/executor, sem simular STT/wake. Core rejeita texto durante busy,
control chars/oversize, grants/ops desconhecidos e duplicatas. UI enfileira uma
entrada quando snapshot está em voo; Cancel limpa entrada pendente. Sem transcript
store ou arquivos pessoais. Controles sem backend ficam desabilitados.

Qt runtime mínimo: PySide6-Essentials 6.12.0 + Shiboken 6.12.0; sem WebEngine/PDF
ou Addons. Regressões PASS: 28 Rust, 5 native wake, A0–A5 32/44/33/67/138/93 checks,
fmt/check/clippy/release/diff-check; zero ignored. Legado HEAD/51 dirty/12 worktrees
confirmados por comandos somente-leitura com GIT_OPTIONAL_LOCKS=0.

Limite: offscreen/software/fixtures EN, não Wayland/fala física/acessibilidade
assistiva real. AWAITING_HUMAN_VALIDATION físico só na rodada consolidada após S5.
Graphify atualizado (488 nós); QML não é indexado por ele e foi verificado diretamente.
Próximo B2: preferências da Base compatíveis/validadas/persistidas/rollback, refletidas
na mesma UI e aplicadas ao mesmo fluxo. Hub e pacote somente após B2/B3.
